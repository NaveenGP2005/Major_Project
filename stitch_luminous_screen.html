"Here is Dijkstra’s shortest-path method, simplified into its pure core intuition:"

Foundational Purpose

Finds the shortest path from a single starting vertex to all other vertices in a network where every path weight is positive.

The Greedy Choice

Always settles the unvisited node with the lowest known tentative distance first, guaranteeing that once finalized, its shortest path is sealed.

Edge Relaxation

Inspects each outgoing neighbor: if traversing the current node yields a quicker journey than previously recorded, update it immediately.

GATE Exam Essential: Remember that Dijkstra cannot handle negative edge weights. If a graph contains negative values, turn to Bellman-Ford instead.
